나불(나무아미타불) 개인정보처리방침

시행일: 2026년 7월 5일 · 최종 수정일: 2026년 10월 17일 · English

MariGoldSoftWare(이하 “개발자”)는 「나불(나무아미타불)」 앱(패키지 com.nabul.app, 이하 “앱”)을 이용하는 분의 개인정보를 소중히 여깁니다. 이 방침은 앱이 어떤 정보를 다루는지 알려 드립니다.

한 줄 요약

이 앱은 이용자의 어떤 정보도 개발자에게 보내지 않습니다. 회원가입이 없고, 광고·분석 SDK 도 없습니다. 수행 기록·발원 노트·즐겨찾기·알림 설정은 이용자의 기기 안에만 저장됩니다. 결제는 Google Play 가 처리합니다.

1. 수집하는 개인정보

  • 회원가입이 없으며, 이름·이메일·전화번호 등 어떠한 개인 식별 정보도 요구하지 않습니다.
  • 수행 기록, 발원 노트, 즐겨찾기, 알림 설정 등 모든 데이터는 이용자의 기기 내부에만 저장됩니다.
  • 어떠한 데이터도 개발자 또는 외부 서버로 전송되지 않습니다.
  • 광고 SDK, 분석(애널리틱스) SDK 를 사용하지 않습니다.

2. 앱 권한

  • 알림(POST_NOTIFICATIONS) — 이용자가 설정한 아침·저녁 수행 리마인더 표시 (선택).
  • 진동(VIBRATE) — 108배 수행 시 목탁 진동 피드백.
  • 정확한 알람(SCHEDULE_EXACT_ALARM) — 리마인더를 이용자가 설정한 시각에 정확히 울리기 위함 (선택).
  • 부팅 완료 수신(RECEIVE_BOOT_COMPLETED) — 기기 재부팅 후 설정된 리마인더를 다시 예약.

모든 권한은 기기 안에서만 동작하며 데이터 수집과 무관합니다.

3. 인앱 결제(후원)

앱은 개발자 응원을 위한 선택적 인앱 결제(커피·목탁·승복 후원)를 제공합니다.

  • 결제는 전적으로 Google Play 결제 시스템을 통해 처리되며, 카드번호 등 결제 수단 정보는 Google Play 가 직접 수집·처리합니다. 개발자는 결제 수단 정보에 접근하거나 저장하지 않습니다.
  • 앱은 결제 완료 여부와 후원 횟수만 이용자 기기 내부에만 기록합니다 — 이 기록 역시 외부 서버로 전송되지 않습니다.
  • 후원은 100% 선택 사항이며, 하지 않아도 앱의 모든 핵심 기능(기도·경전·수행 기록·발원 노트·알림)을 제한 없이 이용할 수 있습니다.

4. 백업 및 복원

  • 마이 탭의 백업 기능은 이용자가 직접 선택한 위치(기기 저장공간 또는 이용자가 고른 저장 앱)에 수행 기록 등을 JSON 파일로 저장합니다.
  • 복원은 이용자가 직접 선택한 백업 파일을 읽어 기기 내 데이터에 추가합니다.
  • 백업 파일은 개발자에게 전송되지 않으며, 개발자는 백업 파일에 접근할 수 없습니다. 저장 위치로 클라우드 앱을 선택한 경우 해당 서비스의 개인정보처리방침이 적용됩니다.

5. 데이터 보관 및 삭제

  • 모든 데이터는 기기 내 앱 저장공간에 보관됩니다.
  • 앱을 삭제하면 기기 내 앱 데이터가 함께 완전히 삭제됩니다. (이용자가 따로 저장한 백업 파일은 이용자가 직접 삭제할 수 있습니다.)
  • 개발자를 포함한 누구도 이용자의 데이터에 접근할 수 없습니다.

6. 아동의 개인정보

앱은 어떠한 개인정보도 수집하지 않으므로, 아동의 개인정보 역시 수집하지 않습니다.

7. 처리방침 변경

향후 클라우드 동기화 등 데이터 처리가 변경되는 기능이 추가될 경우, 앱 내 고지 및 본 문서 갱신을 통해 사전에 안내하고 명시적 동의를 받습니다.

Privacy Policy — 나불(나무아미타불) (Nabul)

Effective: 2026-07-05 · Last updated: 2026-10-17

This Privacy Policy applies to the 나불(나무아미타불) app (package com.nabul.app) provided on Google Play by MariGoldSoftWare ("the developer").

1. Data collected

The app does not collect any personal data.

  • There is no account or sign-up. No name, email, phone number or other identifying information is requested.
  • All data (practice records, vow notes, favorites, reminder settings) is stored only on the user's device.
  • No data is transmitted to the developer or to any external server.
  • No advertising or analytics SDKs are used.

2. Permissions

  • POST_NOTIFICATIONS — show the morning/evening practice reminders set by the user (optional).
  • VIBRATE — moktak vibration feedback during the 108 prostrations counter.
  • SCHEDULE_EXACT_ALARM — fire reminders at the exact time set by the user (optional).
  • RECEIVE_BOOT_COMPLETED — re-schedule reminders after the device restarts.

All permissions operate on the device only and are not used to collect data.

3. In-app purchases (donations)

  • Optional donation purchases are processed entirely by Google Play Billing. Payment details are collected and processed by Google Play; the developer never accesses or stores them.
  • The app records only purchase completion and donation count, on the device only.
  • Donations are fully optional; all core features are available without them.

4. Backup and restore

  • The backup feature saves app data as a JSON file to a location chosen by the user. Restore reads a file the user selects and merges it into on-device data.
  • Backup files are never sent to the developer. If the user chooses a cloud storage app as the location, that service's privacy policy applies.

5. Retention and deletion

  • All data is kept in the app's on-device storage and is deleted when the app is uninstalled. Backup files saved by the user can be deleted by the user.
  • No one, including the developer, can access user data.

6. Children

The app collects no personal data, including from children.

7. Changes

If a feature that changes data handling (e.g. cloud sync) is added, users will be notified in the app and in this document in advance, and explicit consent will be obtained.
